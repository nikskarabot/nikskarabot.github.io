Daljinsko voden model avtomobila

Projekt je bil razvit v sklopu diplomske naloge. Izdelan je bil celoten sistem za daljinsko upravljanje modela vozila, vključno z razvojem programske opreme, načrtovanjem in izdelavo tiskanih vezij ter izdelavo ohišja. Podroben opis delovanja in razvoj sistema sta predstavljena v diplomskem delu na spodnji povezavi.

Strojna oprema

  • ATmega328P
  • nRF24L01
  • NEO-6M GPS module
  • ESC
  • servomotor
  • enkoderji, tipke, joystick-i
  • OLED zaslon

Programska oprema

  • programski jezik C
  • Visual Studio Code
  • PlatformIO
  • KiCad
  • Inventor Professional

Features

  • Implementacija s prekinitvami in enostavnim RTOS-om
  • končni avtomat stanj
  • izdelani 2 tiskani vezji
  • oddajnik in sprejemnik sprogramirana v C-ju
  • Python aplikacija
  • implementirana telemetrija
  • failsafe sistem
  • vodenje preko računalnika ter samostojno daljinsko vodenje
  • pridobivanje informacije o hitrosti iz GPS-modula
  • krmiljenje večih izhodnih naprav
  • PWM-krmiljenje motorja preko ESC-ja
  • izdelan popolnoma nov sistem paketnega komuniciranja
  • merjenje nivoja baterije

Enostaven RC-avtomobil

Projekt je bil izdelan v času srednješolskega izobraževanja. Namen projekta je bila izdelava preprostega radijsko vodenega avtomobila z uporabo platforme Arduino. Projekt vključuje osnovno krmiljenje motorjev, upravljanje servomotorja ter uporabo dodatnih elektronskih komponent za izboljšanje funkcionalnosti vozila.

Strojna oprema

  • Arduino Nano
  • Gonilnik motorjev L298N
  • servomotor
  • LED diode

Programska oprema

  • Arduino okolje

Napetostni usmernik

Projekt predstavlja izdelavo laboratorijskega napajalnika na osnovi kupljenega elektronskega kita. V sklopu projekta je bilo izvedeno spajkanje vezja, povezava vseh elektronskih komponent, izdelava ohišja ter končna sestava funkcionalnega napajalnika.

  • Zaspajkan kupljeni kit usmerniškega vezja.
  • Sestava in povezava vseh delov.
  • Izdelava ohišja.
