# STM32 CAN Logger


## Overview

A standalone CAN bus logging device.


## Hardware

- STM32F407
- CAN transceiver
- SD card storage


## Software

- C
- STM32 HAL
- FreeRTOS


## Features

- 1 Mbps CAN support
- Timestamped logging
- USB data extraction
